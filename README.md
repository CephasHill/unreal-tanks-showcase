# Unreal Tank Combat Prototype

An original tank-combat prototype inspired by classic console tank games and
created for CS455. The project was built from scratch as a systems and gameplay
exercise.

## Features

- Nine playable levels
- Four enemy types with custom AI
- Tank movement and handling
- Projectile and bullet mechanics
- Basic real-time visual effects
- Layered sound system that responds to the number of living enemies
- Round and gameplay progression

## Technical focus

The project demonstrates gameplay architecture in Unreal Engine, including
vehicle-style movement, projectile interactions, enemy decision-making,
level progression, real-time effects, and adaptive audio behavior.

This project is an unofficial educational work inspired by classic tank
minigames. It is not affiliated with or endorsed by Nintendo or the creators
of any source inspiration.

## Repository scope

This is a public showcase repository, not a complete distributable copy of the
Unreal project. The original project contains Unreal Content assets and
generated data that are intentionally excluded here because of repository
size, generated-file noise, and asset-redistribution concerns.
